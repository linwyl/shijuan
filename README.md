# 拾卷 · 本地试卷练习系统

将同一份 Word 或 PDF 中的题目和参考答案整理成可点击的练习卡片，按原文顺序答题，选择后立即核对，并自动记住最新进度。

当前版本：**0.4.1**。本仓库提供可直接使用的 HTML、完整源码压缩包和项目说明；修改代码前，请先解压源码包。

## 主要功能

- 支持 `.docx`、旧版 `.doc`、文字 PDF、扫描 PDF 和混合页面 PDF。
- 支持中文、英文和中英文混合；扫描识别内置简体中文和英文模型。
- 单选题明确支持 A—E 五选项，按原文顺序生成卡片；点击后显示本题参考答案。
- 提供题目、选项和答案核对与修改；缺失或有歧义时提示核对。
- Word 原生数学公式转换排版；PDF 数学内容优先保留原图，并支持人工框选。
- 自动保存试卷、已确认修改和最新作答进度；支持切换保存记录、重新练习和手动删除。
- HTML 内嵌识别资源，日常使用在本机完成。

## 下载和使用

初次使用可下载并解压 **[拾卷_HTML与完整源码.zip](拾卷_HTML与完整源码.zip)**。

在解压后的 `拾卷` 文件夹中：

1. 双击 `启动拾卷.cmd`，通过固定的本机地址打开。启动器需要电脑已有 Node.js 22.13 或更高版本。
2. 也可直接用浏览器打开 `拾卷.html`；直接打开本地文件时，自动保存支持情况以浏览器和页面提示为准。
3. 导入包含题目和参考答案的 Word 或 PDF，先检查“识别核对”，再逐题练习。
4. 等待“已自动保存”后再关闭；下次固定使用同一个浏览器和打开入口。

单独下载 HTML 时，请保存文件后用浏览器打开。GitHub 上的文件预览不是答题页面。

## 修改源码

解压 `拾卷_VSCode项目.zip`，在 VS Code 中打开解压后的 `拾卷_VSCode项目` 文件夹或其中的 `拾卷.code-workspace`。

准备 Node.js 22.13+ 和 pnpm 后，在该源码文件夹的终端运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

生成独立 HTML：

```sh
pnpm build
```

成品位于 `dist/index.html`。检查命令为 `pnpm typecheck`、`pnpm lint` 和 `pnpm test`。完整依赖、测试素材及第三方许可说明均在源码包内。

## 数据保存和使用范围

导入的试卷和作答记录保存在当前浏览器的 IndexedDB 数据库 `paper-cards-memory` 中，不会随本仓库上传，也不会写入 HTML。不同浏览器或不同打开地址的记录不自动共享；清理浏览器网站数据可能清除这些记录。目前没有云同步或记录导出备份。

本系统主要用于个人单选题复习。扫描和复杂排版需要核对；PDF 公式保留原图不等于转换成可编辑公式。旧 `.doc` 的复杂图形和嵌入式公式存在兼容限制。当前不提供正式考试防作弊、多选题练习或主观题自动评分。

开发检查包括解析、公式显示、离线运行和本地保存模拟；完整的浏览器实际操作验收与独立真实试卷准确率统计仍需继续进行。

## 已处理的问题

- 扫描 PDF 导入时的 `Buffer is not defined`：改用浏览器原生解压识别资源。
- Word/PDF 数学内容显示不完整：增加原生公式转换、原图保留和人工框选。
- 刷新后丢失临时进度：增加本地自动记忆和记录管理。
- 题干上方多出一行“0”：0.4.1 修正空阅读材料的显示条件。

第三方代码、组件和合成测试素材的来源及许可证见源码包内 `THIRD_PARTY.md` 和相应许可证文件。
